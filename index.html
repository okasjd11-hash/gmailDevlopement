Welcome to GmailDev

GmailDev is a powerful, developer-first email infrastructure that allows you to send, receive, and track emails with ease. Built on top of enterprise-grade cloud architecture, we provide the tools you need to integrate email features into your applications in minutes.

Note: This documentation is for version 2.0 of the API.

Quick Start Guide

This guide will help you send your first email in under 5 minutes.

JavaScript 
npm install @gmaildev/sdk

Authentication

All API requests must be authenticated using an API Key. You can generate keys in your Dashboard.

cURL 
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.gmaildev.com/v1/user
